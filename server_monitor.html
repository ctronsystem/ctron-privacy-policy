Privacy Policy

Effective Date: April 1, 2026

C-TRON SYSTEM AND SOFTWARE ("we", "our", "us") operates the Server Monitoring application. This Privacy Policy explains how information is handled in the app.

Purpose of the App

This application is designed to monitor server health and check whether configured servers are running or not. It alerts users when a server is down.

Information We Collect

  • Server status (UP/DOWN)
  • Server response time (latency)
  • Downtime and uptime records
  • Network connectivity status (WiFi, Mobile Data, etc.)
  • App settings stored locally

How We Use Information

  • To monitor servers and detect failures
  • To show live server status in the app
  • To maintain downtime history
  • To trigger alerts when server is down

Local Data Storage

All monitoring data such as downtime logs and settings are stored locally on the device. We do not store this data on external servers.

Notifications and Alerts

The app may use notifications, sound, and vibration to alert users when a server is down.

Internet Usage

The app requires internet access to check server availability and connectivity status.

Data Sharing

We do not sell, trade, or share user data with third parties.

Data Security

We take reasonable steps to protect information handled by the app.

User Control

Users can stop monitoring or uninstall the app at any time.

Children's Privacy

This app is not intended for children under 13.

Changes to This Policy

We may update this Privacy Policy from time to time.
